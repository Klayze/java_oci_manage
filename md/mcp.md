# MCP 接入

[English](./en/mcp.md)

让 Claude Code、Codex、Cursor 这类 AI 助手通过面板操作你的服务器。

服务器的密码和私钥始终留在面板里，AI 拿到的只是一个令牌。它能碰哪几台机器、能不能执行命令，都由你发令牌时决定，随时可以收回。

入口：顶部设置 → 「MCP 接入」。需要闪电权益。

---

## 第一步：换正式证书

**Claude Code 和 Codex 连不了自签证书的面板。** 面板默认就是自签证书，不换的话 AI 连不上，而且报错里一般看不出是证书的原因。

在「设置 → SSL 证书设置」里开启 ACME，填服务器 IP 或域名都行，见 [SSL 证书配置](./webssh.md#ssl-证书配置)。已经用反向代理挂了正式证书的可以跳过这步。

没换证书时 MCP 页面顶部会有提示。

---

## 第二步：发令牌

点「新建令牌」，填四项：

| 字段 | 说明 |
|------|------|
| **名称** | 自己认得出来就行，比如 `claude-code-laptop` |
| **权限** | 只读或可执行，见下表 |
| **有效期** | 到期自动失效 |
| **授权主机** | 勾选这个令牌能操作哪几台机器，没勾的碰不到。列表是空的话，先去主机面板保存几台 |

| 权限 | 能做什么 |
|------|---------|
| **只读** | 查看有哪些机器、读取文件，不能执行命令 |
| **可执行** | 执行命令、读写文件，相当于把这个 SSH 账号交给了它 |

---

## 第三步：配置 AI 客户端

令牌生成后**只显示这一次**，同一个页面会给出三份配好的内容：

- Claude Code
- Codex CLI（写进 `~/.codex/config.toml`）
- Cursor 和其他客户端用的 JSON

复制对应的那份，贴进你的 AI 客户端配置里就能用了，地址和令牌都已经填好。

配好之后直接跟 AI 说"看看某某服务器的磁盘占用"之类的就行。执行时间长的命令它会放到后台跑，稍后再来取结果。

## 安全须知

**1. 给 AI 单独建一个没有 sudo 的账号。**

能执行命令，就能在服务器上给自己留后门。别把 root 或你自己日常用的账号给它。

在服务器上建一个专用账号：

```bash
useradd -m -s /bin/bash aiagent
```

然后把这个账号的 `authorized_keys` 放到它自己改不了的地方，编辑 `/etc/ssh/sshd_config`：

```
AuthorizedKeysFile /etc/ssh/keys/%u
```

在面板里用这个账号保存主机，发令牌时只勾这台。

**2. AI 看到的内容会发给 AI 服务商。**

它读了什么文件、命令输出了什么，都会传到 AI 服务商那里。别让它去读私钥、带密码的配置文件、数据库备份。只读权限挡不住这一点 —— 只读只是不能改，不是不能看。

## 收回令牌和查看记录

令牌列表里能看到每个令牌授权了几台机器、什么时候到期、最近一次什么时候用过。

点「撤销」立刻生效，AI 马上失去访问权限，**它正在跑的任务也会一起停掉**。
