## 换 IP 并自动更新 DNS

IP 被墙后最常用的操作：换 IP 的同时把域名解析改过去，效果等同 DDNS。

**准备**：在「设置 → 配置文件设置」里填 Cloudflare 凭据，二选一：

| 方式 | 填什么 | 在哪拿 |
|------|--------|---------|
| API Token（推荐） | `cf_api_token` | Cloudflare 后台新建 Token，权限勾 Zone→DNS→Edit 和 Zone→Zone→Read |
| Global API Key | `cf_email` + `cf_account_key` | 我的个人资料 → API 令牌 → API 密钥 → Global API Key |

推荐 Token：它只能改 DNS，Global API Key 能操作整个 Cloudflare 账户。

**机器人端**：`/oracle` → 「2. ip管理」：

- 换 IP
- 把当前 IP 解析到 Cloudflare 上的某个域名
- 换 IP 并同时更新绑定在这个 IP 上的域名解析
- 删除域名 — 解除当前 IP 绑定的所有域名
- 删掉当前 IP

**Web 端**：云管理 → 实例卡片 → 网络 / IP，能换 IPv4、换 IPv6、多加 IPv4、加 IPv6、挂保留 IP。域名解析在「Cloudflare」标签页里改。

## IP 不通时自动换

`/oracle` → 「16. 监控(自动换ip)」，设好之后不用自己盯着。

设置项：

- 要监控的 IP
- 是否通过代理检测
- 奈飞非自制剧检测
- 指定 IP 段 — 换出来的 IP 不在这个段里就继续换

IP 不通时自动换，并按你的设置更新域名解析。

## 流量超额自动关机

甲骨文免费流量每月 10240 GB（10TB），超了按量扣费。被人刷流量，一晚上扣几十刀的事常有。

云管理 → 「云监控」 → 「+ 新增流量守护」：

1. 选要监控的账号
2. 填流量上限，**建议 9000，别填 10240** — 甲骨文的流量数据有几小时延迟，卡着上限填就来不及了
3. 选「仅通知我」或「自动关机」

选自动关机要知道：

- 一到上限立刻关机，不再确认，关的是这个账号**所有区域**的机器
- 手动开回来后如果流量还超着，1 小时内会再被关
- 关太久的话，A1 这种难开的机器可能被甲骨文收回，重开要重新抢

## 机器停了自动开回来

云管理 → 「云监控」 → 停机保活，两个开关：

| 开关 | 作用 |
|------|------|
| 实例停机通知 | 机器意外停了发 Telegram |
| 停机自动开机 | 停了自动开回来 |

被流量守护关掉的账号，当月不会自动开机，免得刚关就开、流量接着跑。

机器人端的「9. 实例状态监控通知」「10. 实例状态监控自启」是同一个设置。

## A1 免费额度体检

甲骨文 ARM 免费额度按账号算，超开的账号可能被回收。云管理 → 「A1 配置体检」可以批量查、批量降。

1. **配置体检** — 查各账号的 ARM 用量，标出「超开 / 已符合额度 / 查询失败」
2. **降配** — 可以按账号降（在该账号几台机器间平均分）、批量降（勾选多个账号一起提交）、逐台降
3. 目标配置默认 2 核 12G，可以改

注意：

- 只降不升，**不会自动删机器**
- 容量不足会自动重试直到成功，结果发 Telegram，任务列表里可以取消
- 正在运行的机器降配时会重启
- 目标核数不能少于机器台数，不然没法平均分，先逐台降或删掉几台
- 删机器只能一台台手动确认

非闪电用户只能查当前账号，闪电用户可以一次处理全部账号。

## 域名和证书到期监控

云管理 → 「域名监控」。每天自动检查域名注册到期和 SSL 证书到期，快到期时发 Telegram。

两种添加方式：手动填，或者点「从 Cloudflare 导入」把托管的域名一次导进来。

到期前 30 天、14 天、7 天、1 天和过期当天各提醒一次。

注意：

- 填**主域名**（`example.com`），别填子域名。子域名查不到注册到期时间，会显示「未知」，证书到期照常能查
- 中文域名直接搜就行
- 添加、导入、开启提醒需要闪电权益；停用、删除、查看、立即检查不需要

## 给每个账号配独立出站 IP

多个甲骨文账号都挂在同一台客户端上时，它们访问甲骨文用的是同一个 IP。想让某些账号走各自的代理，可以按账号单独设。

**Web 端**：设置 → 配置文件设置 → 点开要改的账号 → 面板底部「API 出站代理」。填代理地址，有账号密码就填上，没有就留空，点「保存代理」。

停用要点「移除代理」，把输入框清空再保存是不行的。

概览页的账号列表里有「出站代理」一列，一眼能看出哪些号配了。

**机器人端**：`/oproxy`。

## 启动盘掉了或误删实例

启动盘和实例是分开的，盘还在，数据就在。

云管理 → 卷管理。卸下来的启动盘都在「未附加启动盘」面板里；实例没挂启动盘时，点「启动盘」会直接带你过去。

| 情况 | 做法 |
|------|------|
| 实例还在，盘被卸下来了 | 在未附加启动盘面板点「附加」，选实例挂回去。实例要先关机 |
| 实例删了，盘留着 | 用这块盘重新开一台，见 [甲骨文开机教程 — 从启动盘开机](./boot-oracle.md#从启动盘开机) |

卸启动盘也要先关机。

## 进不去系统时救机器

SSH 连不上、防火墙把自己关在外面、系统起不来，用串行控制台。

云管理 → 实例 → 串行控制台，浏览器里直接出一个终端，相当于接了显示器和键盘。

如果系统已经坏到起不来，可以用内置的 Netboot.xyz 进救援系统，关键步骤前会停下来等你确认。

## 一次给多台机器执行命令

Web SSH 终端 → 批量命令。勾选多台主机，输入命令，一次发出去。

结果按主机分开显示，可以接着在同一批机器上执行下一条，不用重新选。

## 把云上已有机器导进会话列表

不用一台台手填 IP。主机面板 → 云主机同步，支持甲骨文、AWS、GCP、Azure、DigitalOcean、SolusVM、VirtFusion。

导进来的只有 IP 和名称，用户名和密钥还要配一次。密钥在「SSH 密钥管理」里存一份，之后所有连接都能选。

只想临时连一下的话，各云的实例卡片上有「SSH」按钮，点了直接连。

## 升级客户端和看日志

顶部设置菜单里的「客户端升级」和「客户端日志」，不用登服务器，也不需要闪电权益。机器人的「32. 升级客户端」「34. 查询最新日志」作用相同。

**升级**

页面显示当前版本和最新版本。

- **立即升级** — 下载新版并重启
- **强制升级** — 不管版本直接重装。版本检查失败时用这个
- **重启服务** — 只重启，不升级

5 分钟内只能点一次。升级时终端会断开，一般 1~3 分钟恢复。

**日志**

可以选显示 100 / 300 / 1000 行，按关键字过滤，开自动刷新，一键复制。出问题找客服时复制一段发过去。
